# CloudHub 桌宠形象

`alpaca-sprites.png` 是参考用户提供的 `alpaca_desktop_pet_assets` 概念素材，由 imagegen 生成并进行背景透明化的位图。源素材保留在用户目录，本仓库不包含概念图中的示例业务数据或 UI 截图。

- 画布：1536 × 1024，RGBA，6 列 × 4 行，每格 256 × 256。
- 第 1 行：待机 6 帧；第 2 行：跑动 6 帧；第 3 行：水枪 6 帧。
- 第 4 行：睡觉、开心、好奇、提起、工作、担心。
- 水滴由本地 CSS 独立绘制；不请求远程图片。
- 点击穿透以实际帧 alpha > 32 为角色范围，翻转与显示方向一致。
- 使用位置：仅桌面宠物窗口。桌宠默认关闭。

动画素材不是人工逐帧骨骼动画，造型在帧间有轻微差异；后续可在保持格数、画布和状态映射一致时替换更精细的素材。

## 贴边收起

手动将桌宠拖到显示器可用区域任意边缘（16 个逻辑像素范围）后，原生窗口收缩为头部大小，暂停自主移动。`pet-heads.json` 为所有形象提供统一的头部裁切坐标，React 展示和 Rust alpha 点击穿透读取同一数据。鼠标悬停或单击不展开；拖动头部可拉出桌宠，新运维消息及生活提醒会自动恢复完整窗口。关闭消息后保持展开，不自动收回。自动漫游不触发收起，保存的仍是正常窗口位置。
