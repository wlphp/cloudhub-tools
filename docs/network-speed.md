# 网络测速

入口：软件商店 → 网络测速。支持商店公共页面/弹层宿主，以及可选侧栏入口。仅桌面端运行；浏览器预览不借用本地 API 所在机器测速，移动端暂不接入。

## 使用

默认使用国内七牛 CDN，也可选择国内支付宝 CDN、Cloudflare 自动边缘节点，或者提供自建兼容节点的公网 HTTPS 基础地址。两个国内 CDN 只测下载和 HTTP 延迟，不支持上传，不会将海外上传结果混入国内测速。它们使用公共文件的 HTTPS 范围下载（只在内存中计数，不保存或执行文件），严格校验 HTTP 206、Content-Range 与返回大小；CDN 正常缓存属于该模式的测量对象。

选择每方向 5/10/15 秒、总载荷上限 50/200/500 MiB 后开始。国内 CDN 总预算用于下载；双向节点下载和上传各分配一半预算，达到预算提前结束。每次最多四个并发请求，可停止；离开页面后任务继续，重新打开可查看和停止。历史仅在本地 SQLite 保留最近 20 次，包含已停止及失败的部分结果，不参与跨设备同步。

测速主动使用无 HTTP 代理的客户端，VPN/TUN、系统路由仍会影响路径。工具不修改系统代理、网络或网卡设置。测速节点可看到来源 IP；应用不上报测速摘要，不保存传输内容。

## 本机 IP 和归属地

打开页面后单独查询 IPIP.NET 的公开 `https://myip.ipip.net/` 接口，显示公网出口 IP、大致归属地和运营商；可手动刷新。只使用不超过 4 KiB 的响应，并校验公网 IP 与文本长度。查询失败保留明确提示，不阻止测速，不把原始响应写入日志、错误或历史。服务会看到来源 IP；查询展示值只在当前页面内存保留，不写入测速历史。

本机内网 IP 为系统到公网的默认 IPv4 路由选出的网卡地址，通过 UDP connect 查询路由但不发送数据包，不枚举全部网卡。VPN/TUN 可能改变内外网出口；IP 归属地是服务数据库的估计，不能作为设备精确位置。

## 测量口径

- 下载/上传 Mbps：阶段有效载荷字节数 × 8 ÷ 实际阶段耗时 ÷ 1,000,000；包含请求开销，四连接合计。MB/s = Mbps ÷ 8。
- 下载按流读取并计数；拒绝压缩，验证返回大小。Cloudflare/自建节点拒绝缓存响应，国内 CDN 允许边缘缓存响应。上传使用随机内存载荷，仅在成功响应且响应体读取完整后计为有效吞吐。上传实时曲线按已确认请求绘制，慢连接可能出现间隔。
- HTTP 延迟：一次预热后六次 GET 请求的完整往返耗时中位数；Cloudflare/自建节点为零字节，国内 CDN 为一字节范围请求。波动为相邻样本耗时差绝对值均值。包含服务端处理时间，不能解释为 ICMP Ping；不测量 UDP 丢包。
- 载荷流量为下载接收字节加已提交上传请求大小的保守估算；取消、失败的上传可能只发送一部分。流量上限约束请求载荷预算，不包含 TLS、HTTP、TCP 重传等开销及小响应体，不能视为网卡精确流量。
- 达到预算、跨境路由、节点限流或服务器带宽不足都可能低估本地宽带；结果仅代表到所选节点的路径，不承诺等同运营商签约带宽。

## 节点协议与边界

基础地址末尾补 `/`，端点相对基础路径解析：

| 请求 | 要求 |
| --- | --- |
| `GET __down?bytes=N&nonce=<随机值>` | 成功状态码，返回 N 字节不可压缩、不缓存的数据；N=0 返回空响应 |
| `POST __up` | 接受 `application/octet-stream` 载荷，全部接收后返回成功状态码，响应体不超过 4096 字节 |

自定义节点只允许无 URL 凭据、查询参数或片段的 HTTPS 地址。解析后的所有 IP 必须为允许的公网地址；固定该次 DNS 结果，不跟随重定向，不发送 Cookie/认证信息。不支持内网测速服务器或自签名证书。节点名称、区域信息不作为任意 HTML 执行；只读取受限的 Cloudflare `cf-meta-colo` 字段，不读取 IP 等响应字段。

Cloudflare 官方项目公开记录了上述接口：[cloudflare/speedtest](https://github.com/cloudflare/speedtest)。本实现没有引入或复制其 SDK。开源代码许可不构成公共接口的可用性、容量或商业 SLA 承诺，服务的使用仍受服务方条款约束。部署自建节点前应确认带宽费用和接口兼容性。

## 实现与验证

- React：`NetworkSpeedPlugin.tsx`、`network-speed.css`；`speed-test.ts` 定义原生调用契约。
- Rust：`core/speed_test.rs` 负责引擎与历史，`commands/speed_test.rs` 限制主窗口和单任务互斥。
- SQLite：迁移 58 创建独立本地历史表，不添加同步触发器。
- 核心测试覆盖公网地址与输入限制、并发预算、历史裁剪、有效吞吐、拒绝截断、失败上传和阻塞请求取消；真实公共节点小流量测试为显式运行的 ignored 测试。
