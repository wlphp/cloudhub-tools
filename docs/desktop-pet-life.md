# 宠物生活提醒

入口：系统设置 → 桌宠与运维预警 → 生活陪伴 → 地区与生活提醒。

- 默认关闭，手动配置并保存。地区不读取定位；作息以北京时间计算。
- 默认 09:00 上班、12:00–13:30 午休、18:00 下班，提前 10 分钟收尾提醒。时间可修改，当前支持同一天内的白班。
- 上班、午餐、午休结束、下班前、下班各问候一次。喝水默认每 60 分钟，按上午/下午开始时间计算间隔；午休、下班、休息日暂停，可选起身活动提醒。
- 喝水气泡出现时可跑动 12 秒。打开聊天或菜单、操作宠物、减少动态、隐藏宠物及免打扰时不跑动。可确认或延后 10 分钟。
- 原生后台每 20 秒检查，本地 SQLite 保存提醒 ID 与处理状态。重启去重，休眠错过的提醒不集中补发；应用退出后停止。后台继续运行需开启托盘驻留。
- 生活气泡等待聊天及运维气泡关闭后显示。只在桌宠可见时展示，不抢夺主窗口焦点。

## 日历

内置[国务院 2026 年放假及调休安排](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)，包含调休补班。可填写额外休息/工作日期覆盖。未知年份在界面提示，并暂停未明确指定的工作日提醒；关闭法定节假日过滤后按周一至周五运行。自定义日期仍优先。

## 天气预警

来源：[中央气象台预警信号](https://www.nmc.cn/publish/alarm.html)页面使用的公开 `https://www.nmc.cn/rest/findAlarm` 数据。每 15 分钟查询一次，全国列表在本机按省份、城市名筛选并包含省级预警；城市留空关注全省。当前支持大陆省级地区。

只展示 24 小时内发布的预警列表信号，跳过解除信息。预警原文由经过校验的 ID 构造中央气象台 HTTPS 地址；不执行或打开供应商返回的任意地址。此公开页面接口并无稳定性保证，查询失败会明确显示错误及最近成功时间，不将失败视为无预警。各页、总时限、响应大小均有上限，未完整读取时保留旧状态。天气预警独立于工作日过滤。

## 验证范围

Rust 覆盖节假日/调休、自定义日期、作息时间点、午休与下班暂停、去重、免打扰、延后、地区过滤及无效响应；另有显式运行的公开接口 smoke test。Playwright 以原生接口模拟验证设置、跑动、延后、聊天/运维优先、原文操作、减少动态及 375/768/1024/1440 宽度。真实系统休眠和跨显示器移动仍依赖现有 Tauri 窗口边界。
