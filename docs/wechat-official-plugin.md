# 微信多开官方内置插件

入口：CloudHub Tools → 软件商店 → 官方应用 → 微信多开 → 设置。

本插件由 CloudHub Tools 提供，随当前应用编译打包，不是腾讯发布的插件。
首版支持 Windows 桌面端。浏览器预览与其他系统不提供本地启动能力。

## 使用

1. 安装微信 Windows 客户端。
2. 从微信托盘菜单退出所有微信；插件不会自动结束微信会话。
3. 自动检测路径，或选择本地的 `Weixin.exe` / `WeChat.exe`。
4. 选择 2～5 个启动窗口，点击“批量启动”。
5. 根据实际打开的登录窗口分别登录。微信版本可能自行合并窗口，批量启动请求成功不代表多开成功。

设置保存在当前客户端的本地存储中。插件停用不关闭已打开的微信。
首版不提供聊天记录隔离、消息聚合、第三方代码加载或插件商店在线下载。

## 按账号保存登录配置（实验性）

参考 [MultiWeChatManager Python 分支的配置切换流程](https://github.com/wfql1024/MultiWeChatManager/blob/python/func_core/acc_func_core.py)，实现“保存当前配置 → 恢复所选配置 → 启动 → 等待新窗口”。没有引入 Python 运行时或执行该项目代码。

1. 在设置中点击“自动检测数据目录”。程序检查微信保存的路径设置、用户文档及本地固定磁盘的浅层目录，以完整的限定配置文件是否存在匹配：一个结果自动填入，多个结果在“匹配的数据目录”中选择。若未找到，点击“选择位置查找”，选 D 盘等大致位置继续搜索，不必事先知道准确根目录。仍可通过“选择数据目录”直接指定已知路径。
   这里选择的是微信已在使用、包含 `all_users` 或 `All Users` 的数据目录，不是 `Weixin.exe` 所在目录，也不是自行新建的空账号文件夹。选择程序目录及其直接子目录时会给出专门提示。
   自动检测只读注册表的路径值、微信旧版专用路径设置文件与目录/文件元数据，不读取登录配置或聊天记录的内容。跳过网络路径及目录链接；默认磁盘查找深度为三层，所选位置查找深度为六层，每次最多检查约 120000 项、最多返回 32 个目录，使用约 8 秒的查找预算。达到上限会明确提示，可缩小范围重试。单个兼容结果自动填入，其他客户端版本的数据不会自动选用。未匹配、错误或取消时不清空已选择目录。
2. 手动登录账号 A，再从系统托盘退出所有微信。输入“工作号”等名称，点击“保存当前配置”。
3. 启动微信、切换到账号 B 并完成登录，再退出全部微信，保存为另一个配置。
4. 在“已保存配置”中逐个点击“恢复并启动”。先准备各自的登录窗口并核对头像，全部准备好后再逐个点击微信的登录按钮。先登录第一个账号可能导致配置进入占用状态，后续账号无法恢复。不要并发恢复多份配置，也不要使用上面的“批量启动”恢复不同账号，该按钮仍只重复打开当前配置。此顺序只是兼容性尝试，不保证所有版本的窗口准备阶段都允许切换配置。
5. 如需撤回配置变更，退出全部微信，选择相应时间的“恢复前备份”，点击“恢复备份”。

已保存配置列表下方提供“批量启动已保存配置”。先从托盘退出全部微信，再点击此按钮；按当前列表顺序，仅处理与当前客户端版本兼容的账号配置，跳过恢复备份。复用单账号的原生恢复与启动命令，不并发写入共享配置。

“启动节奏”默认使用实验性的快速尝试模式：恢复并提交一个启动请求后，额外等待 50 毫秒，再处理下一项，不检查或等待登录窗口出现。可选 0、20、50、100、200 毫秒；间隔不包括解密、配置恢复、备份落盘和系统调度耗时，并非保证两次进程启动正好相隔这么久。仍保留备份、失败回滚和文件占用检查，不关闭微信或其他进程的句柄。快速模式可能再次显示相同头像、合并窗口或遇到占用，完成提示仅统计已提交请求，不宣称已打开指定账号窗口。

也可选“等待窗口出现”，沿用此前逐个检测新窗口的方式。过程中显示进度；若失败，右上角提示已提交/已准备数量和失败配置，并停止后续任务。任务完成后由用户核对窗口、头像并分别登录，再次批量前需退出已准备的微信。关闭设置停止后续启动，当前已提交给系统的启动请求会完成，已打开窗口需用户自行关闭。此操作不保证绕过微信文件占用或窗口合并限制。

保存配置时会校验当前选择的客户端与配置文件类型，拒绝把旧版 3.x 的配置保存给 4.x 客户端使用。已有快照保持原样，列表按快照中已有的类型标明“微信 3.x / 微信 4.x”，版本不匹配时禁用“恢复并启动”；切换为对应客户端后可重新启用。登录配置没有实现跨大版本转换，不能把“旧版微信目录里有配置”当作“已找到当前 4.x 账号”。

不需要的配置可在“已保存配置”列表右侧点击“删除”，确认后仅移除 CloudHub 保存的那一份快照，微信原始数据、聊天记录、其他账号快照与恢复备份均保留。版本不匹配的旧配置也可删除。取消或删除失败时保留原列表记录；不会自动删除用户已经保存的配置。

固定文件范围与上游配置地址一致：4.x 为 `all_users/config/global_config` 与 `global_config.crc`；3.x 为 `All Users/config/config.data`。每个文件最多 1 MiB；缺失、空文件、链接及被占用的文件均拒绝处理，不尝试猜测其他文件。

快照和恢复前备份存储在 CloudHub 本地数据目录的 `wechat-login-configs` 下，使用已有本机加密方式，不上传，不把内容返回 React；开发版与发布版沿用各自的数据目录和密钥。不要把它当作跨设备迁移包。快照总数上限为 200；如需人工整理，退出 CloudHub 后先备份整个目录，保留需要的账号快照与恢复备份。

这实现登录配置切换，不提供完整文件系统、注册表或聊天数据隔离；重复保存同一个账号仍会得到同一头像。微信可能让凭据失效、合并启动请求、保持文件占用或在退出时改写配置。窗口出现只说明检测到新的微信窗口，不代表对应账号已成功登录。免扫码和自动登录由微信客户端与授权状态决定，插件不模拟点击登录。

## 实现边界

- `src/features/plugins/registry.ts`：官方内置插件元数据。
- `src/features/plugins/OfficialPluginsPage.tsx`：插件入口、启停与启动设置。
- `src/platform/clients/plugins.ts`：仅原生客户端调用。
- `src-tauri/src/commands/wechat_plugin.rs`：路径验证、安装检测、进程检查和并发启动。
- `src-tauri/src/commands/wechat_sessions.rs`：限定文件快照、加密备份、恢复和逐个启动。
- 不使用 shell 拼接启动微信，不修改微信程序或互斥量，不强制关闭文件句柄，不读取聊天数据库。仅用户点击账号配置操作时读写上述登录配置文件。
- 写回前先获取所有目标文件的句柄，允许兼容的只读句柄存在，但拒绝并行写入句柄；保存并落盘恢复前备份，再原位写回。普通写入失败时尝试还原。断电或进程崩溃可能需要手动使用恢复备份，不能把多文件写入当作原子事务。微信禁止共享写入或自己持有写入句柄时仍会停止，不能把调整共享方式当作绕过文件锁。

## 验证

执行 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml`，
`cargo test --manifest-path src-tauri/Cargo.toml wechat_plugin::tests --lib`，
以及 `npx playwright test tests/ui/official-plugins.spec.ts`。

UI 模拟测试只能证明界面与参数契约；真实多开需要用已安装微信检查登录窗口数量。
账号配置读写功能的自动检查仅使用临时合成文件和模拟命令；未读取或改写本机实际微信登录配置，也未验证真实账号的不同头像、免扫码或同时登录。这些按用户要求由用户实测。

2026-10-15 早期数据检测只覆盖旧版路径设置，因此仅发现 3.x 目录。随后补充微信 4.x 专用的 `%APPDATA%/Tencent/xwechat/config/<32位十六进制标识>.ini` 路径定位：只接受有界文件中的完整绝对路径或 `MyDocument:` 路径设置，支持 UTF-8、UTF-16 与系统 ANSI 编码，不输出原始 INI 内容。参考公开项目的[路径设置说明](https://github.com/wzh4464/wechat-offload-onedrive)及[纯路径解析实现](https://github.com/ydotdog/wechat-export-macos/blob/main/config.py)，不执行其数据迁移、数据库访问或配置写入逻辑。已在本机仅通过路径提示与文件存在性确认新的 `OneDrive/xwechat_files` 数据根目录内有 4.x 的两份限定配置文件；实际保存与账号恢复仍由用户验证。

2026-10-15 本机验证：Windows 微信 `4.1.15.13`，通过 Rust 插件启动逻辑提交两个请求，
检测到两个 `Weixin` 进程分别持有不同的非零主窗口句柄。未执行账号登录；其他版本仍需验证。

需手动复验真实启动时，先退出微信，再运行：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml launch_installed_client_manually --lib -- --ignored --nocapture
```

该测试默认跳过，显式执行会打开本机已安装微信的两个窗口。
