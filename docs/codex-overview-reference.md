## 与参考项目的明确差异

- 测智结果保留在本次窗口，关闭后清空；未迁移参考项目的历史记录、供应商测试、后台恢复与完整可执行 HTML 预览。
- 停止测试或唤醒会停止尚未提交的请求，已提交请求等待结束或超时。
- 不展示缺乏本地真实数据来源的团队名称、单账号费用与访问统计。
- 未迁移参考项目的 Agent Identity、更多平台账号、自动计划、远程服务商及其独立工作流。
- 原生账号能力仍仅在桌面端可用；浏览器预览不读取或处理真实凭据。

## 验证方法

- `npm run build`：TypeScript 与打包。
- `cargo check --manifest-path src-tauri/Cargo.toml`：原生命令与注册。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib core::codex::`：Codex 解析、存储、协议及边界。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib reauthorization_rejects`：身份不一致及批量身份拒绝。
- `npx playwright test tests/ui/codex-management.spec.ts tests/ui/codex-theme-consistency.spec.ts`：模拟原生命令的完整 UI 流程和响应式边界。

自动化测试不调用真实账号进行登录、额度消耗或模型测试。

## 启动预览（图 2）

- 账号底部终端按钮打开“Codex 启动预览”，创建独立实例保留在“应用多开”。
- 预览包含账号、目标实例、Token 有效期元数据、订阅日期、额度条和重置倒计时、固定快捷操作与切换按钮。
- 默认实例复用准备/确认切号和默认客户端启动；独立实例可在停止后更换绑定账号，启动失败明确显示账号已切换。
- 官方 CLI 刷新认证并加密保存轮换结果；默认客户端持有的刷新授权不创建第二个写入者，需客户端续期后导入。
- 上下文窗口、压缩阈值、默认模型通过官方 CLI 配置 RPC 读写；仅回传允许字段，配置指纹冲突拒绝覆盖。
- 订阅、重置确认、API 账号池、CLI 启动、标签/备注、刷新额度、导出复用实际原生命令。
- 差异：第三方 API 路由入口目前打开现有 API 服务配置，未迁移 Cockpit 的外部供应商混合路由；模型管理目前提供目标实例默认模型配置，未迁移完整模型目录。
- 界面回归采用模拟原生命令；临时无凭据目录已验证本机官方 CLI 模型/上下文/压缩配置读写和其他配置保留，未用真实账号验证刷新与启动。

## 账号详情补充

账号信息入口支持按需显示和原生复制AT、RT、ID Token、API Key；默认遮挡，未提供值明确标注。支持密码、2FA文本、邮件网页、手机号、独立其他备注的本机加密保存，账号列表不带凭据。2FA当前为保存/显示/复制原始秘钥，不包含动态验证码计算；新增补充资料暂不进入Cockpit/Sub2API账号导出格式。

## 卡片字段对齐（2026-10-20）

- Team Name、登录方式、用户ID从本地认证数据提取有长度约束的展示信息，不传输Token；未知登录方式明确标注，工作区ID保留悬停提示。
- 加备注移至重置/代理同行，订阅空态统一为未获取订阅信息；底部显示含年份的额度更新时间。
- 仍有语义差异：参考底部日期为created_at，本项目未保存导入创建日期；目前显示明确标注的额度更新时间。参考请求/Token/费用为窗口内本地API统计与价格估算，尚未接入。标准为账号速度配置，尚未移植持久化与实际生效链路。额度窗口保持接口实际周期，不硬编码截图中的5 Week。
