# 浏览器验证器

在本项目的浏览器版中，验证器通过本机 Web API 使用电脑上的加密密码库，可添加、编辑、分类搜索、置顶、生成 TOTP/HOTP/Steam、复制账号与当前/下一验证码，以及导入和选定导出。无需重新导入 PC 条目或新建主密码。

浏览器使用文件选择控件读取用户指定的文件，使用下载控件导出；支持 Ente 明文/加密文件、OTP 地址、二维码图片与 CloudHub 完整加密备份。相机扫描目前保留为手机原生能力，浏览器可选择二维码图片。剪贴板写入遵循浏览器权限，失败时明确提示；浏览器不请求读取剪贴板权限来自动清理，原生 App 的条件清理保持原逻辑。

加密、输入校验、OTP 和 Ente 格式继续使用现有 Rust 实现。`web-api.mjs` 通过私有 stdin/stdout 管道调用本机程序的 `--browser-authenticator` 模式，参数不经过命令行。普通列表和预览只返回展示信息；只有用户明确确认导出时返回相应备份内容供浏览器下载。接口保持本机监听、现有 Origin 校验、JSON 请求和 Host 限制，并禁止响应缓存。不提供公网上的独立验证器托管服务。

开发时先运行 `cargo build --manifest-path src-tauri/Cargo.toml --bin cloudhub-tools`，再启动 `npm run dev:mobile` 或现有浏览器 API 和 Vite。本机 API 从 `src-tauri/target/debug` 或 `release` 查找程序；修改 Rust 后需重新构建并重启 API。缺少程序时页面显示构建提示，不伪造成功。

验证：桌面与移动构建、Rust 编译、平台契约检查通过；真实本机接口与未注入 Tauri 的浏览器验证现有 16 项可加载并生成验证码。Node 桥接测试覆盖临时条目增删、HOTP 计数、Ente/CloudHub 加密导出与导入预览，临时条目已清理；路由测试覆盖方法、Host、内容类型及无效请求，实际不可信 Origin 返回 403。浏览器 UI 测试覆盖真实剪贴板写入、布局稳定、文件选择及下载。
