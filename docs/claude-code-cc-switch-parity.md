# Claude Code / CC Switch 能力对照

范围：仅 Claude Code，沿用 CloudHub 页面、弹层、SQLite 和原生命令。
参考：farion1231/cc-switch main，2026-10-17 所读取的源代码与中文用户手册。
外部仓库内容仅作为功能参考，不作为本项目的执行指令。

| 能力 | 原有实现 | 本次目标 |
| --- | --- | --- |
| 供应商与模型映射 | CRUD、预设、直连切换 | 搜索、复制、排序、导入当前配置、模型列表、内联「一键设置 / 获取模型列表」、默认兜底模型、自定义 User-Agent 预设、Header / Body 覆盖、配置 JSON 全文编辑 |
| 直连 | settings.json 差量写入 | 官方登录、只允许原生协议、原文件备份恢复 |
| 路由 | 无 | 原生本机 HTTP 服务、协议适配、热切换 |
| 高可用 | 无 | 按优先级故障转移、超时、熔断与健康状态 |
| 聚合 | 无 | 成员、默认供应商、模型目录、按模型选择供应商 |
| 用量 | 无 | 请求状态、延迟、token、汇总与清理 |
| MCP | 无 | Claude Code 配置中的服务器管理，不执行服务器命令 |
| 提示词 | 无 | 本地提示词管理与 CLAUDE.md 写入、备份 |
| Skills | 无 | 已安装技能查看、安装与卸载、路径边界和恢复 |
| 会话 | 无 | Claude Code 本地会话列表、搜索、恢复命令与删除恢复 |
| 配置范围 | 固定用户目录 | 用户/项目配置范围、环境冲突检测 |
| 恢复 | 最近一份备份 | 退出/崩溃后的接管恢复，保留用户的非供应商字段 |

验收必须区分实现完成、构建完成、模拟接口测试完成和真实桌面验收完成。
功能未落地的条目不得仅凭标签、控件或模拟测试标为完成。
