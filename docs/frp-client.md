# 本机 FRP 客户端

“内网穿透”管理当前运行云枢 Tools 的电脑上的 frpc，与“终端管理”中的托管主机无关。浏览器预览不提供安装、进程或本机面板操作。

## 使用流程

1. 点击“一键安装 / 更新”，安装官方 frp v0.71.0 Windows amd64 或 arm64 客户端。安装包会校验 SHA-256 后提取到本机应用数据目录。
2. 在“全局客户端面板账号”设置一次面板用户名和密码；所有本机 frpc 实例共用这份凭据。
3. 添加多个 FRP 服务端连接。每个连接分别配置名称、地址、连接端口和可选 Token；Token 在本机加密保存。
4. 在选中服务端下添加穿透规则。每条规则只属于一个服务端。保存服务端或规则后点“应用此服务端配置”启动或更新该实例。
5. 服务端列表显示连接进程状态；规则表显示 frpc 返回的单条代理状态。每个实例的本机管理面板仅监听 `127.0.0.1`，端口从 7400 起自动分配。

## 行为与数据

- 每个服务端拥有独立的 frpc.toml、面板端口和受管 frpc 进程；编辑或停止一个服务端只操作该实例。
- 全局面板密码和各服务端 Token 通过 Rust 加密路径保存在 SQLite。frpc 配置文件需要包含运行凭据的明文副本，保存在当前用户的 `CloudHubTools/frp/server-<id>/` 目录中；请保护 Windows 登录账户及应用数据目录。
- v7 单服务端配置升级时，面板凭据迁移为全局设置；原服务端和规则成为第一个连接及其规则。旧 `frpc.toml` 不会被自动删除，应用新配置后会在按服务端 ID 的目录生成新文件。
- frpc 由云枢 Tools 管理；关闭云枢 Tools 会结束所有由该进程管理的实例。重新打开后可分别启动服务端连接。
- 一键安装当前支持 Windows amd64 与 arm64。浏览器预览会明确显示不支持，不会模拟本机能力。

## 状态含义

- “已保存”仅表示本机数据库记录已更新；“已应用”表示磁盘配置与当前数据库内容一致。
- “运行中”来自 frpc 的客户端状态接口，按每条已启用代理显示；进程存活本身不代表代理已注册成功。
- 修改全局面板账号或密码后，各运行实例的配置会显示待应用；逐个应用对应连接后生效。
- 连接失败时检查服务端连接端口、Token、服务端端口策略/防火墙以及本机目标服务。凭据不会进入前端状态回显或错误文本。
