# 羊驼桌宠与运维预警

## 使用

桌面应用的「系统设置 → 羊驼桌宠与运维预警」提供两个独立开关，默认均关闭。

- 启用羊驼：待机、眨眼、短程跑动、喷水、睡觉、开心、好奇、提起和告警表情。可调整大小、活动范围及活跃程度，默认静音，并遵循系统减少动态设置。
- 单击查看状态，右键打开喷水、休息、提醒、回到屏幕下沿、设置与隐藏菜单。拖动移动，位置保存在本机。菜单和提醒只通过明确关闭按钮或 Escape 关闭。
- 隐藏不停止运维预警；隐藏后停止动画与漫游。关闭桌宠会销毁其窗口。
- 运维预警开启后独立于当前页面在 Rust 后台执行。默认间隔5分钟，最短1分钟，不重叠执行；手动巡检至少间隔1分钟。
- 关闭主窗口后继续巡检，需要开启「关闭主窗口后驻留托盘」。托盘提供打开主窗口、显示羊驼、退出应用。电脑关机、休眠、应用退出时无法实时巡检。
- 免打扰继续保存提醒记录，暂停弹出提醒。

## 数据与提醒

- HTTPS证书：本地证书和已同步宝塔站点证书的有效期。它不代表网站实时提供的证书；请在证书管理刷新宝塔站点记录。
- 服务器：最近同步云资源中的到期日期，提醒中注明缓存时间；没有日期的资源保持未知，需刷新资产。不自动续费。
- 宝塔：显式开启后，通过 `GetNetWork` 和 `GetConcifInfo` 只读接口检查连接、CPU、根磁盘以及已安装组件状态。连续两次异常才提醒。面板连接失败仅表示无法检查，不直接判定服务停止。接口不提供明确状态时保持未知。
- 同一告警去重，每日最多重复提醒一次，升级与重新发生可再次提醒；支持暂缓1小时，恢复后解除。未知数据不判为恢复。资源移除、规则关闭单独注明停止监测。
- 羊驼可见时显示气泡；羊驼关闭或隐藏时使用独立的 CloudHub 桌面提醒窗口。这是应用提醒卡，不是操作系统通知中心的历史记录。全部记录可以在系统设置查看，最多保留300项。
- 不自动重启服务、执行SSH、续签证书、部署证书或续费。提醒入口打开对应管理页面。

## 执行边界

React只控制动画和交互，Rust负责窗口、命中透明度、位置限制和巡检；设置与有界提醒记录复用SQLite的`client_preferences`，未新增数据库schema。新桌宠窗口的自定义命令有单独白名单，不允许调用凭据读取等其他命令。

宝塔监测请求禁止HTTP重定向，超时12秒、响应最大2MiB，解密凭据只在Rust短时使用。完整环境响应可能包含敏感字段，不能传入事件、UI或日志，只提取服务布尔状态和资源指标。

浏览器预览明确显示不支持，不模拟原生窗口或常驻。手机入口不导入桌宠组件，手机命令白名单不变。macOS透明窗口配置使用Tauri平台专用配置；Linux仍受窗口管理器限制。

## 验证说明

自动化覆盖：关闭默认值和输入边界、到期时间解析、SQLite提醒记录往返、去重/升级/暂缓/恢复/移除、未知状态、透明页面、喷水交互、明确关闭、独立预警开关、失败保存、减少动态、隐藏停止、独立提醒窗口。界面测试使用模拟IPC，不代表原生窗口实测。

原生验收待完成：Windows透明窗口与鼠标穿透、拖动后位置、不同DPI及多屏断开、托盘驻留与退出、应用重启后恢复、休眠恢复、真实宝塔版本兼容与性能。隔离桌面实例的启动命令被自动审批拒绝，原因是`blocked by policy`，不能把此部分写为通过。macOS/Linux未进行原生运行验证。
