# 数据管理：SQL 迁移与字段加密备份

两种方式仅在桌面客户端可用，手机扫码迁移保持独立。

| 功能 | 明文 SQL 导入导出 | 加密备份与恢复 |
| --- | --- | --- |
| 用途 | 查看、编辑、选择业务配置并跨设备合并 | 保存数据库快照，恢复某个时间点的数据库内容 |
| 文件 | `.sql`，不加密 | `.chdb`，数据库快照与恢复密钥打包，默认无密码，可选整包密码保护 |
| 凭据 | 包含所选配置的明文密码、Secret、令牌、私钥 | 敏感字段保留数据库原有密文，对应恢复密钥随包携带 |
| 导入行为 | 先预览，默认跳过重复，也可覆盖重复；保留其他数据 | 普通备份无需密码，密码备份先解锁；先预览，确认后替换普通数据库内容 |
| 文件限制 | 最大 64 MB、100000 条记录 | 最大 256 MB |

## 明文 SQL

导出时选择范围并确认“包含明文凭据”后，选择保存位置。关联父记录会自动一并导出，例如 SSH 的云账号、FRP 规则所属的服务端。

支持云账号、云主机 SSH、托管主机及 RDP、面板连接、当前证书及私钥、流水线连接、FRP 设置、服务端、规则及远程客户端配置。证书历史版本、来源与部署关联不在 SQL 范围内。

不包含 Codex、验证器、AI 配置、浏览器数据、笔记、客户端偏好、同步身份、日志和云资源缓存。进程运行状态和外部文件也不会由 SQL 迁移。

SQL 只支持本客户端定义的 CloudHub 格式，要求数据库 schema 版本一致、表与列匹配；不能导入任意第三方 SQL 脚本。允许修改数据字面值，禁止新增 DDL、表达式或其他 SQL 操作。为保持字段对应关系，名称以 `_ciphertext` 结尾的列在导出文件中也保存**明文**，不要依据列名判断文件是否安全。

导入时先用本机密钥重新加密凭据，再显示数量与冲突预览；前端不会收到导入的明文凭据。云账号按厂商和 Access Key ID、托管主机按地址/端口/用户名、面板按地址、证书优先按指纹等业务标识匹配；SSH、RDP、FRP 规则等按映射后的关联主键匹配。覆盖采用更新方式，保留现有实体的同步身份和子记录。关联 ID 会重新映射，新增记录生成新的同步身份。

确认时重新检查最新数据并在事务中导入，失败则回滚；导入前在数据目录生成 `.before-sql-` 数据库快照。该快照沿用本机密钥，不是带独立密码的可移植备份。SQL 原文件仍为明文，导入不会替用户删除它。

## 字段加密备份

点击“创建备份”可选择是否勾选“使用密码保护”，每次打开默认不勾选。不勾选时无需输入密码，保存为原有 `CHDBMIG1` 格式，包含 SQLite 快照、恢复所需本地密钥及 SHA-256 校验信息；不增加整包密码加密层。

勾选后输入并确认备份密码（至少 8 个字符、最多 1024 个 UTF-8 字节），将同一份数据库和恢复 key 使用 Argon2id 派生密钥、AES-256-GCM 整体加密，保存为 `CHDBENC2` 格式。每次使用随机盐和 nonce；密码不保存，忘记后无法恢复。取消勾选会清空密码，普通备份不会传递或使用先前输入的密码。两种模式都保留敏感字段的原有密文和恢复 key，区别在于是否对整个包额外加密。

云账号密钥、SSH 密码和私钥等原本加密的字段保持 AES-256-GCM 密文，不会像 SQL 那样解密后导出。普通配置仍可读取，完整文件同时包含解密所需的 key，因此持有文件的人能够恢复凭据；字段加密不等于备份文件具有独立访问保护，请勿公开分享。SHA-256 用于检测损坏，不提供防篡改认证；导入时仍须验证文件格式、大小及 SQLite 完整性。

备份是数据库快照，不包含数据目录外的文件，也不打包整个应用目录、浏览器用户目录或其他外部资源。虽然数据库快照内可能有 Codex 与验证器表，恢复明确保留**当前设备**的 Codex 账号/配置和验证器数据；它们需通过各自专用功能迁移。恢复前保留本机数据库与密钥的回退文件，并重置导入的同步设备身份与旧设备信任。

“导入备份”选择文件并校验，只加入本机备份列表，不立即覆盖数据；“恢复”无需密码，直接进入预览，最终确认才执行覆盖。“下载”复制原备份文件、保留原格式；“打开位置”打开本机备份目录。

普通 `.chdb` 显示“内含恢复密钥 · 无需密码”，不再提供“加密副本”入口。新创建及此前已经生成的 `CHDBENC2` 文件均显示“密码备份”：通过“导入密码备份”输入原密码导入，恢复时同样需要原密码。两种格式均保留支持，不会自动修改或删除已有文件。

## 云同步

数据管理下方增加云同步，支持 WebDAV 与 S3 兼容存储。它传递 CloudHub 数据库备份，不进行逐条记录合并。浏览器预览和手机端不执行远端数据库同步。

1. 选择方式，填写服务地址与凭据。WebDAV 使用账号及应用密码；S3 使用存储桶、区域和长期 Access Key ID / Secret Access Key，可切换路径风格或虚拟主机风格；暂不支持临时 STS 凭据。
2. 设置远程根目录和配置名，同一组设备使用相同值。文件位置为 `<服务地址>/<根目录>/v1/<配置名>/database.chdb`；路径风格 S3 在服务地址后额外插入存储桶名。
3. “测试连接”仅检查 WebDAV 根目录或 S3 存储桶的访问权限，不创建对象；上传另需写权限。保存后才可上传、下载，修改配置后需重新保存。
4. 上传前明确确认替换远端文件；新文件使用 `If-None-Match: *`，已有文件使用强 ETag 和 `If-Match`。不提供强 ETag 的服务不能覆盖已有备份，可改用新的配置名。远端并发修改返回冲突，不强制覆盖。
5. 下载最大 256 MB，验证格式、校验值及数据库完整性后进入现有恢复预览，用户确认才替换数据库；恢复前保留本机回退快照及密钥。

默认云备份与普通本机备份一致：字段保持密文，恢复 key 包含在文件中，持有完整文件可恢复。启用“使用密码保护云备份”后，数据库和 key 一起经过 Argon2id + AES-256-GCM 加密。另一台设备下载时需在此配置中填写同一备份密码。云备份密码需要在本机加密保存，以支持后台自动上传；这与本机单次备份对话框的“密码不保存”不同。

云存储密码、Secret Access Key 和云备份密码通过既有本地加密保存，不返回界面，不通过通用偏好接口读写。输入框留空仅在相同服务和账号下保留已保存的存储凭据，更换地址或账号必须重新填写。上传快照会移除云同步连接配置，恢复时保留当前设备的配置并用新的数据库密钥重新加密。

自动同步默认为关闭，实际行为是应用运行期间自动上传：每 10 秒检测业务数据表，变化后静置约 30 秒上传，连续变化最多延迟约 120 秒；失败至少间隔 5 分钟重试。日志、缓存表和云同步自身偏好写入不触发上传。它不会自动下载或合并，远端 ETag 与本机记录不同时停止覆盖。下载进入预览后暂停自动上传；恢复后关闭自动上传并保留暂停提示，重启仍保持关闭，检查数据后可重新开启并保存。

仅允许 HTTPS，除非明确勾选允许 HTTP（仅适用于可信内网）。不跟随重定向，不透传服务端响应内容或带凭据 URL。连接超时 15 秒，单请求总超时 180 秒。
