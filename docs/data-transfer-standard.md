# CloudHub 数据导出、备份与迁移标准

策略版本：1。适用于明文 SQL、本地 `.chdb` 备份、云端备份、手机扫码迁移。

## 统一范围

| 数据 | 是否纳入 | 说明 |
| --- | --- | --- |
| 云账号 | 是 | 包含访问凭据、分组与备注 |
| SSH、RDP、托管主机 | 是 | 包含密码、私钥等连接配置；状态和监控数据重新获取 |
| 宝塔面板 | 是 | 包含面板连接、凭据和站点证书关联；站点实际文件、数据库和远端服务不属于本地备份 |
| HTTPS 证书 | 是 | 包含证书、私钥、历史版本、来源和 ESA 部署关联；不携带临时签发订单状态 |
| 流水线 | 是 | 保存连接配置及凭据；不保存运行记录、任务日志和缓存 |
| FRP | 是 | 保存本地/远程客户端、服务端、规则及凭据；程序包重新安装，恢复不启动进程 |
| Claude 管理 | 仅供应商 | 包含供应商 API Key；不包含 MCP、提示词、技能、工作区、会话及运行日志 |
| Codex 管理 | 仅供应商相关配置 | 包含模型供应商、供应商密钥、聚合和成员；不包含登录账号、OAuth、实例绑定及本机配置备份 |
| AI 配置 | 是 | 包含模型、请求参数、API Key |
| 备忘录 | 是 | 包含正文、分组、标签、账号密码和提醒规则；导入后重建提醒队列 |
| 指纹浏览器 | 仅配置 | 包含环境配置和代理凭据；不包含内核、额外下载包、浏览器用户目录及 Cookie 文件 |
| 验证器 | 是 | 包含完整验证码种子、类型、位数、算法、周期、HOTP 计数及条目信息 |
| 可迁移偏好 | 是 | 仅明确允许的主题、语言、导航、供应商排序与界面/备忘录偏好 |
| 操作日志、API 日志、请求日志、事件 | 否 | 目标设备已有记录保留 |
| 云资产缓存、探测结果、运行队列、设备身份、同步信任 | 否 | 目标设备保持自身身份，业务状态按需重新获取 |
| 下载包、程序、机器路径、同步/云备份连接设置 | 否 | 沿用目标设备设置 |

## 各入口的默认行为

| 入口 | 模块范围 | 回收站 | 凭据表示 |
| --- | --- | --- | --- |
| 明文 SQL 导出 | 默认全选，可按模块选择 | 默认不含，可选包含 | 明文，包含私钥和 OTP 种子 |
| 本地备份 | 全部允许的业务模块 | 包含 | 字段加密并携带恢复密钥；可选密码保护整个包 |
| 云端备份 | 与本地备份相同 | 包含 | 与本地备份相同 |
| 手机扫码迁移 | 默认全选，可按模块选择 | 默认不含，可选包含 | 原生端生成载荷，通过现有加密传输发送 |

手机可保存桌面专属配置，执行能力仍由对应平台提供。浏览器预览不提供原生备份恢复和扫码接收能力。

## 导入与恢复

1. 导入先预览模块和数量，再确认写入。凭据在原生进程中转换，用目标设备现有密钥重新加密。
2. SQL 支持“合并保留已有”和“合并覆盖重复”；扫码默认合并并保留已有。
3. 本地及云端恢复可选择模块，并支持替换所选模块、合并保留已有、合并覆盖重复。桌面恢复默认替换；手机默认合并。
4. 依赖模块自动带入。例如证书历史依赖证书，供应商密钥依赖供应商，备忘录依赖分组。父记录使用目标设备 ID 重新建立关联。
5. 替换时，若删除父记录会影响未选模块，整次恢复回滚，提示选择关联模块或改用合并。
6. 同种子的验证器合并为已有条目；HOTP 计数取较大值。相同条目标识对应不同种子时拒绝导入。
7. 本地备份、云端恢复及 SQL 导入前自动保留目标数据库快照。此快照用于本机故障回退，包含本机原数据，不属于对外迁移包。
8. 数据写入在事务内完成，发生记录、关联或唯一值冲突时回滚。恢复不会自动切换供应商、写入 Claude/Codex 外部配置文件或启动业务进程。

## 兼容性与限制

- SQL 和扫码统一载荷要求数据库版本一致，载荷最多 64 MB，最多 100000 条 SQL INSERT；可分模块处理较大数据。
- 新扫码协议为版本 5；手机界面遇到旧协议时提示更新电脑端。既有同步协议继续保留供原有接口使用。
- 旧 `.chdb` 包读取后在隔离副本上升级数据库，并只恢复允许的数据。旧包没有携带可恢复的验证码密钥，因此保留目标设备验证器。
- 旧密码验证器库需先在现有验证器入口完成迁移，新备份随后能携带完整种子。
- 导入明文 SQL 仅解析 CloudHub 定义的 INSERT 字面量格式，不执行文件内任意 SQL。

## 后续模块接入规则

统一目录位于 `src-tauri/src/core/data_transfer.rs`，采用明确允许的表清单。新数据表默认不参与任何迁移入口。

新增业务模块时，需在同一次变更中定义：表和字段范围、凭据转换、父子依赖、去重规则、运行字段清理、回收站行为及跨设备往返验证。界面从原生目录获取范围，禁止各入口自行维护另一套清单。
