# 移动验证器与电脑迁移

手机原生应用在“更多”中提供“验证器”，位于云流水线下方。浏览器版通过本机 API 也可使用验证器，见 [浏览器验证器说明](authenticator-browser.md)。无需创建主密码；手机使用 Android Keystore / iOS Keychain 保护的本机根密钥，按独立用途派生验证器加密密钥，不复制电脑的密钥文件。

支持桌面已有的 TOTP、HOTP、Steam、当前与下一码、账号复制、搜索、服务商分类统计、分组、置顶排序、卡片/列表、批量选择删除、手动添加编辑、Ente 明文/加密导入及 CloudHub 完整加密备份。邮箱单独一行并换行，服务商图标本地打包。账号、当前码与下一码复制使用固定浮层提示，不挤动卡片；HOTP 仅点击下一码推进计数。

手机还可扫描 OTP 二维码或通过系统文件选择器导入二维码图片。拒绝相机权限时可继续使用图片或手动导入。进入后台清除页面数据、输入和原生会话，返回自动重新打开。相机和系统文件选择器暂时遮挡页面时保留正在进行的导入导出操作。

电脑点击“手机扫码迁移”，打开“验证器”页签，勾选要迁移的条目；可以仅迁移验证码。手机在“更多 → 系统设置 → 导入数据”扫描电脑二维码，核对账号和类别，选择条目后确认。遵循现有电脑批准手机和一次性加密传输流程，单次总计最多 100 条配置。验证码种子只在原生进程中解密和处理，预览只含展示信息。手机使用自己的密钥重新加密保存；同种子条目合并，HOTP 计数不回退，同标识不同种子拒绝导入并回滚事务。

包含验证码的迁移包使用第三版协议，电脑和手机都需要包含本功能的版本。新版本保留第一、二版包兼容。持续增量账号同步不包含 OTP，整库备份继续排除验证器；验证码换机可使用一次性二维码迁移或独立加密备份。

## 验证证据

- 桌面 `npm run build`、移动 `npm run build:mobile`、平台命令契约及 Rust 命令边界检查通过。
- Android `aarch64-linux-android` 原生 `cargo check` 通过，使用已安装 NDK 28.2.13676358；保留已有未使用代码警告。
- 移动 UI 回归验证入口顺序、375px 布局、三个字段复制与卡片位置稳定、搜索、权限拒绝、前后台清除及恢复、导入重复项默认跳过、选定导出、二维码迁移选择。
- 桌面迁移测试验证可以只选择一个验证码生成迁移二维码；原有桌面验证器回归覆盖手动编辑、HOTP、分类、批量选择及 Ente 导入导出。
- Rust 验证第三版加密包往返、错误口令拒绝、旧版缺省字段兼容、预览无种子；仓库测试验证不同设备密钥重新加密、元数据保留、HOTP 不回退及碰撞事务回滚。

UI 测试模拟 Tauri 调用。当前无连接的手机，未做真实相机、系统文件选择器、剪贴板及后台切换的设备运行验收；iOS 未在 Windows 上编译。本任务没有生成发行安装包。
