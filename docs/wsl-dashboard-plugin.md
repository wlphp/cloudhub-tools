# WSL 管理官方插件

入口：CloudHub Tools → 软件商店 → 官方应用 → WSL 管理。

插件仅在 Windows 桌面端可用，通过 Tauri 原生命令调用系统 `wsl.exe`。浏览器预览会明确提示不支持，不会模拟成功。发行版名称和状态来自 `wsl --list --verbose --all`；命令错误只返回稳定提示，不把 WSL 原始输出、用户路径或 Linux 输出写入日志和界面。

## 当前支持

- 查看已注册发行版、运行状态、WSL 版本和默认项。
- 启动、停止发行版、设为默认发行版。
- 备份发行版为 TAR：用户选择保存位置，导出成功后保存正式备份；取消和失败不会显示备份成功。可从安装页的本地 RootFS 导入恢复为新实例。
- 删除发行版：独立确认弹层显示永久删除警告，必须输入完整发行版名称后才能确认；Rust 同时校验确认名称。可先备份，点击遮罩不关闭确认弹层。
- 停止全部 WSL 虚拟机（操作前二次确认）。
- 从限定名称清单安装常见发行版；安装前提示 Windows 可能请求管理员权限或重启。

所有用户可控命令参数均作为独立参数传给 `wsl.exe`，不经过 shell 拼接。发行版控制前会重新读取列表，确认目标仍已注册。安装参数受固定清单约束。

## 尚未支持

参考项目还包含发行版迁移与导入导出、VHDX 磁盘挂载、计划任务、端口转发与防火墙规则、HTTP 代理、USB/IP、系统托盘、开机启动和应用内升级管理。这些能力依赖独立的 Windows 系统集成和生命周期管理，目前尚未迁移到 CloudHub Tools；当前插件不能视为与上游功能完整等价。
